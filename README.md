## ✨ Overview

This project is an **interactive Excel dashboard** analyzing **Vrinda Store’s retail performance** across:
- sales trends
- customer demographics
- order outcomes
- sales channels

The dashboard is designed to support **practical business decisions** in:
- inventory planning  
- marketing focus  
- channel strategy  
- fulfilment performance  

It mirrors the type of analysis used by **retail analysts, category managers, and operations teams**.

---

## 🎯 Why this project matters

Retail data is often fragmented across platforms and reports.

This project demonstrates how to:
- consolidate performance metrics into a **single view**
- identify demand patterns and customer segments
- surface fulfilment and return risks
- present insights in a **stakeholder-friendly format**

The focus is **clarity and actionability**, not raw data volume.

---

## 🧠 Key insights surfaced

### 📈 Orders & Sales Trends
- Monthly view of order volume vs revenue
- Identifies seasonality and demand fluctuations

### 👥 Customer Demographics
- **Gender split:**  
  - Women: **61%**  
  - Men: **39%**
- **Age groups:**  
  - Adults: **53.1%**  
  - Seniors: **33.8%**  
  - Teenagers: **13.1%**
- Enables targeted marketing and assortment decisions

### 📦 Order Outcomes
- Delivered: **53%**
- Returned: **25%**
- Refunded: **12%**
- Cancelled: **10%**

Highlights fulfilment efficiency and post-sale risk.

### 🗺️ Geographic Performance
- Top states by sales:
  - Uttar Pradesh
  - Telangana
  - Tamil Nadu
  - Maharashtra
  - Karnataka

Supports regional inventory and logistics planning.

### 🛒 Channel Performance
- Amazon: **41%**
- Flipkart: **32%**
- Meesho: **27%**

Enables channel-level revenue and dependency analysis.

## 📊 Dashboard design

The Excel dashboard includes:
- Pivot tables for dynamic aggregation
- Slicers for quick segmentation
- Clear visual hierarchy for fast interpretation
- Separation of raw data, calculations, and visuals

The layout is optimised for **non-technical stakeholders**.
